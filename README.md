# Gegeen ✻

> **AI-powered Mongolian florist** — `gegeen.mn`
>
> Mood, occasion, recipient-ийн дагуу AI-аар хамгийн тохирох цэцэг сонгож өгдөг
> e-commerce платформ. Letterbox flowers, subscriptions, AI co-writer, Memory Garden.

## Stack

| Layer | Tech |
|-------|------|
| Frontend | Next.js 14 (App Router, TypeScript, Tailwind) |
| State | Zustand (cart, UI) + Server Components (data) |
| Backend | Supabase — Postgres + Auth + Storage + Realtime + Edge Functions |
| Payment | QPay (Mongolian QR payment) |
| Deploy | Vercel |
| AI Image | Pollinations.ai (cached → Supabase Storage) |

## Local development

```bash
# 1) Install dependencies
cd apps/web
npm install

# 2) Configure environment
cp ../../.env.example .env.local
# Fill in NEXT_PUBLIC_SUPABASE_URL + NEXT_PUBLIC_SUPABASE_ANON_KEY

# 3) Push migrations (if not already)
DB_PASSWORD='your-db-password' node scripts/migrate.mjs

# 4) Start dev server
npm run dev
```

Open <http://localhost:3000>.

## Environment variables

See `.env.example` for full list. Critical:

```env
NEXT_PUBLIC_SUPABASE_URL=https://...supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGc...

# Server-side only
SUPABASE_SERVICE_ROLE_KEY=eyJhbGc...
SUPABASE_ACCESS_TOKEN=sbp_...   # for CLI ops (`supabase gen types`)
SUPABASE_DB_PASSWORD=...        # for `scripts/migrate.mjs`

# QPay (https://merchant.qpay.mn)
QPAY_USERNAME=
QPAY_PASSWORD=
QPAY_INVOICE_CODE=

NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

## Database

Migrations live in `supabase/migrations/`. Push them with:

```bash
# Option A: programmatic (uses pg npm)
cd apps/web
DB_PASSWORD='...' node scripts/migrate.mjs

# Option B: Supabase CLI (requires `supabase login`)
supabase link --project-ref <ref>
supabase db push

# Option C: Dashboard
# Open Supabase Dashboard → SQL Editor → paste supabase/setup.sql → Run
```

Regenerate TypeScript types after schema changes:

```bash
cd apps/web
npm run types          # runs `supabase gen types typescript --linked`
```
